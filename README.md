<div style="background-color:#f5f5f5; padding:20px; border-radius:12px;">
  <h2 style="color:#0d6efd;">📝 Project Overview</h2>
  <ul>
    <li><strong>Project Name:</strong> DA_PROJECT</li>
    <li><strong>Goal:</strong> Build a complete, beginner-friendly Data Analysis workflow from scratch.</li>
    <li><strong>Problem Statement:</strong> Analyze raw datasets to extract insights, visualize patterns, and generate reports automatically.</li>
    <li><strong>Proposed Solution:</strong> Develop a Python-based EDA engine and Streamlit frontend to perform comprehensive analysis including:
      <ul>
        <li>Overview & summary statistics</li>
        <li>Missing data & outlier detection</li>
        <li>Correlation & distribution analysis</li>
        <li>Time series & categorical summaries</li>
        <li>Interactive visualizations</li>
      </ul>
    </li>
    <li><strong>Reference / Learning Resources:</strong> 
      <ul>
        <li><a href="https://pandas.pydata.org/docs/" target="_blank">Pandas Documentation</a></li>
        <li><a href="https://docs.streamlit.io/" target="_blank">Streamlit Docs</a></li>
        <li><a href="https://scipy.org/docs.html" target="_blank">SciPy Stats</a></li>
      </ul>
    </li>
  </ul>
</div>
